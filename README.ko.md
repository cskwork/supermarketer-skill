# supermarketer-skill 스타터

제품 마케팅 전략, 메시지·카피, 포스터·소셜 크리에이티브, 이미지, 영상 제작을 하나의 검증 가능한 워크플로로 묶는 스킬 명세입니다.

## 핵심 원칙

- 설득보다 제품 사실을 먼저 확인합니다.
- 모든 사실·수치·비교 주장은 근거 ID와 연결합니다.
- 채널 규격과 정책은 실행 시점에 공식 자료로 다시 확인하고 날짜를 기록합니다.
- 제작자와 검수자를 분리합니다.
- 이미지·영상 도구가 없으면 결과물을 만든 척하지 않고, 명확히 표시한 제작 패키지로 대체합니다.
- 게시, 발송, 광고비 집행은 별도 명시적 승인이 있어야 합니다.
- 출시 전에는 `LAUNCH_READY`만 검증할 수 있습니다. 실제 데이터가 없으면 `PERFORMANCE_VALIDATED`라고 선언하지 않습니다.

## 파일

- `SPEC.md`: 전체 제품·기능·운영 명세
- `SKILL.md`: 얇은 루트 라우터 초안
- `agents/`: 역할별 지시
- `reference/`: 필요할 때만 읽는 플레이북
- `templates/`: 실행별 작업 폴더 템플릿
- `tests/`: 계약 테스트와 시나리오
- `scripts/`: 향후 구현할 검증 게이트 인터페이스

## 권장 1차 구현 범위

먼저 리서치, 포지셔닝, 카피, 정적 크리에이티브, 이미지, 감사(AUDIT), 런치 키트를 구현하고, 영상은 렌더러가 없을 때도 완전한 제작 패키지를 제공하도록 설계하는 것이 안전합니다.
