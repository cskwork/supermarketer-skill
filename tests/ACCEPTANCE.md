# Acceptance contract

## Structural

- [ ] `SKILL.md` has valid frontmatter with name and trigger-focused description.
- [ ] Every mode in the router maps to a reference and deliverable.
- [ ] Every referenced local file exists.
- [ ] Every producer role has an independent review path.
- [ ] Templates contain stable status, evidence, claim, and asset anchors.
- [ ] Root skill remains a router rather than embedding every playbook.

## Marketing integrity

- [ ] Product truth precedes persuasive factual copy.
- [ ] Every factual/quantitative/comparative/testimonial/promotional claim resolves to evidence.
- [ ] Current channel specs are dated and sourced.
- [ ] No synthetic testimonial or fabricated proof.
- [ ] Rights, privacy, and generated-asset lineage are recorded.
- [ ] Regulated contexts create a current jurisdiction decision gate.

## Media

- [ ] STATIC requires an actual rendered file.
- [ ] IMAGE fallback is labeled and is not represented as a generated file.
- [ ] VIDEO fallback is `PRODUCTION_PACK_ONLY` and contains script, storyboard, shot list, VO, on-screen text, captions, prompts/assets, and edit plan.
- [ ] Metadata requirements are recorded for every requested placement.

## Approval and status

- [ ] External publish/send/schedule/spend requires explicit approval.
- [ ] Final output separates readiness from performance.
- [ ] `Z-READY.md` cannot claim performance.
- [ ] `Z-VALIDATED.md` requires real data and a predeclared rule.
