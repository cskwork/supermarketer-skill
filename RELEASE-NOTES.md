# SuperMarketer 0.0.1 release notes

Release date: 2026-07-15

This first release combines SuperMarketer's evidence-grounded execution core with the complete 47-specialist MarketingSkills knowledge set through independent mode and specialty routing.

## Included

- 12 bilingual execution modes and 47 independently selected marketing specialties.
- Exact vendored `cskwork/marketingskills` snapshot at commit `130847d0945555c43b0b1774e2a4f99d35a32ebe`, including 47 playbooks, 145 references, 45 evaluations, one asset, and the upstream MIT license.
- Per-file SHA-256 manifest and executable integrity gate for source provenance, catalog/frontmatter agreement, required playbooks, and snapshot tampering.
- Dependency-free Node.js 20+ CLI with exact `--mode` and `--specialty` overrides.
- Persistent product/brand truth and isolated run vaults that record both selected playbooks.
- Structured evidence, claims, channel, deliverable, asset, review, approval, production-pack, state, and measurement records.
- 12 aggregate readiness gates, media inspection, path containment, symlink rejection, rights/lineage checks, independent-review enforcement, and honest media fallbacks.
- Transactional readiness and performance attestations, deterministic ZIP packaging, and scoped publish permits with no external execution.
- English/Korean documentation, GitHub Pages landing content, certified examples, CI for Node.js 20 and 22, and 83 contract and adversarial tests.

## Deliberate integration boundaries

The package does not bundle upstream executable marketing CLIs, media-provider credentials, publish/send/spend implementations, reviewer identity authentication, legal approval, malware scanning, or a universal analytics-export parser. Vendored tool mentions are optional guidance; missing tools never permit invented evidence or fake outputs. Current platform, pricing, legal, and channel facts still require current authoritative verification.

Local SHA-256 records establish file consistency, not digital-signature authenticity. Use signed release artifacts or immutable storage when provenance and non-repudiation matter.
