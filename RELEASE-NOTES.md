# SuperMarketer 1.0.0 release notes

Release date: 2026-07-12

This release delivers the complete provider-neutral execution core for evidence-grounded product marketing and creative production.

## Included

- 12 bilingual routing modes and a thin `SKILL.md` router.
- Dependency-free Node.js 20+ CLI.
- Persistent project truth and isolated run-vault scaffolding.
- Structured evidence, claims, channel, deliverable, asset, review, approval, production-pack, and measurement records.
- 12 aggregate readiness gates and focused executable wrappers.
- Media metadata inspection, path containment, symlink rejection, rights/lineage checks, independent-review enforcement, and honest media fallbacks.
- Transactional `Z-READY.md` certification with report SHA-256, certified-file integrity manifest, file-membership checks, and post-certification injection detection.
- `verify-ready`, deterministic ZIP packaging, package manifest, and checksum sidecar.
- Explicit scoped publish permits with no external execution.
- Transactional `Z-VALIDATED.md` performance validation with source, rule, and calculation-evidence hashes plus `verify-results`.
- GitHub Actions CI for Node.js 20 and 22.
- A certified complete COPY example and a short-video fallback example.
- 37 automated contract and adversarial tests.

## Deliberate integration boundaries

The package does not bundle media-provider credentials, publish/send/spend implementations, reviewer identity authentication, legal approval, malware scanning, or a universal analytics-export parser. Actual media generation occurs through documented host adapters; actual external actions require a separate authorized system.

Local SHA-256 records establish file consistency, not digital-signature authenticity. Use signed release artifacts or immutable storage when provenance and non-repudiation matter.
