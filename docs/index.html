Default loop

Frame to measure — with a built-in publish gate.

The maker never self-approves. Adversarial review and deterministic QA must both pass before anything is marked ready.

01

Frame

Capture objective, audience, funnel stage, offer, KPI, and falsifiable readiness criteria in BRIEF.md.

02

Ground

Build EVIDENCE.md, dated CHANNEL-SPECS.yaml, and CLAIMS.yaml from current, high-trust sources.

03

Strategize

Minimum positioning, message hierarchy, offer/CTA, concept, and channel role. Creative brief for visual/video.

04

Produce

Fresh-context specialists build each deliverable. Everything is logged in ASSET-MANIFEST.yaml with lineage.

05

Improve

A separate role checks brief coverage, edge cases, crops, legibility, captions, alt text, and variants.

06

Adversarial review

Fresh reviewers try to disprove readiness. They make no production edits.

07

QA & package

Deterministic artifact checks plus independent review, mapped to evidence in QA.md.

08

Publish gate

Post/send/schedule/spend only after explicit approval naming destination, timing, account & budget.

09

Measure

Only real post-launch data can flip status to PERFORMANCE_VALIDATED.

Repository map

A thin router. Depth loaded on demand.

supermarketer-skill/
 ├─ SKILL.md   — the thin router
 ├─ SPEC.md   — full functional spec
 ├─ agents/   — 13 role contracts
 ┃   product-marketer · researcher
 ┃   copywriter · creative-director
 ┃   visual / image / video producer
 ┃   channel · localization specialist
 ┃   brand-claims · creative reviewer
 ┃   qa-auditor · experiment-analyst
 ├─ reference/   — mode playbooks
 ├─ templates/   — run-vault files
 ├─ tests/   — acceptance contracts
 └─ examples/ · scripts/
  • SKILL.md Router

    Classifies the objective into one mode, states it in a line, and routes to the right playbook. Never embeds the playbook itself.

  • agents/ Roles

    Each role has a contract. Producers and reviewers are always separate — the creator of an asset cannot be its only reviewer.

  • reference/ Playbooks

    On-demand depth per mode: research, positioning, campaign, copy, static, image, video, channel-specs, QA, publishing, and more.

  • templates/ Run-vault

    Every run gets a dated folder: BRIEF, EVIDENCE, CLAIMS, CHANNEL-SPECS, ASSET-MANIFEST, QA — and Z-READY only when all gates pass.
