# Channel specification playbook

Channel constraints are time-sensitive. Fetch them at run time.

## Source policy

Prefer official platform documentation. Record:

- channel,
- placement,
- source,
- checked date/time,
- dimensions/aspect ratios,
- duration,
- file types/size,
- text constraints,
- safe zones,
- caption/accessibility requirements,
- policy notes,
- confidence.

Do not rely on memory for current platform specifications.

## Adaptation

Specifications are necessary but not sufficient. Also adapt:

- attention context,
- user intent,
- sound behavior,
- scroll/feed behavior,
- copy density,
- proof type,
- CTA,
- sequencing,
- organic versus paid placement.

## Fallback

If official documentation is inaccessible:

- use a reputable secondary source,
- record the limitation,
- lower confidence,
- and request confirmation before high-cost production or publishing.
