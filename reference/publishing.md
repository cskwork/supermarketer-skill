# External publishing gate

Ordinary production does not authorize external action.

## Actions behind this gate

- publish/post/upload,
- schedule,
- deploy,
- send email/SMS/push/DM,
- use a customer/contact list,
- launch paid media,
- change budget/bid/targeting,
- replace live creative,
- submit to an external review or marketplace.

## Required approval record

- exact destination/account/workspace,
- final asset IDs and versions,
- copy version,
- audience/recipient scope,
- schedule,
- budget/spend where applicable,
- tracking parameters,
- rollback/stop plan,
- explicit user approval text and timestamp.

## Verification after action

Record:

- external ID/URL where available,
- timestamp,
- asset version,
- destination,
- delivery/publish result,
- screenshots or tool output,
- any partial failure.

No approval means package only.
