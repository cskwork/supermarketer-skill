# Static creative playbook

Applies to posters, banners, carousels, flyers, social posts, display ads, retail/event signage, and similar assets.

## Before production

Confirm:

- placement and current spec,
- actual viewing size/distance,
- primary message and CTA,
- copy version,
- brand tokens/assets,
- imagery source,
- logo and legal/disclosure rules,
- crop/safe zones,
- output and editable formats.

## Composition

- One dominant idea.
- Clear reading order.
- Strong signal-to-noise ratio.
- Intentional whitespace or density.
- CTA is visible but not detached from the message.
- Proof and disclosure are legible.
- Imagery communicates meaning.
- Product/UI visuals are truthful.

## Variants

Re-layout for each placement. Check:

- crop,
- text line count,
- logo position,
- CTA placement,
- safe zones,
- thumbnail readability,
- mobile viewing.

## QA

- exact dimensions/aspect ratio/file type,
- no clipped text or marks,
- small-size preview,
- computed contrast when source colors are available,
- correct dates/prices/terms,
- working URL/QR,
- claim IDs,
- source/editable and rendered paths,
- rights/AI status.
