# Post-launch measurement playbook

`MEASURE` requires real data.

## Validate the data

- source and access,
- date range/time zone,
- metric definitions,
- attribution model,
- exclusions,
- audience/placement,
- control/baseline,
- tracking changes,
- missing or duplicated events.

## Analyze

- calculate the primary KPI,
- compare against control/baseline,
- report absolute and relative differences,
- include uncertainty/confidence where appropriate,
- inspect guardrails,
- segment only with sufficient data,
- identify confounders and implementation issues.

## Interpret

Distinguish:

- descriptive result,
- association,
- randomized causal effect,
- directional learning.

## Output

- reproducible calculations,
- results and uncertainty,
- data-quality limits,
- creative/message/channel learning,
- recommendation: scale, iterate, stop, or gather more data.

Write `Z-VALIDATED.md` only when the predeclared condition is met.
